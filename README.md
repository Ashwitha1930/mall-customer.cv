# mall-customer.cv
Customer Segmentation Project
Objective
Segment customers based on behavior and demographics using machine learning techniques.

Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Algorithm Used
K-Means Clustering

Features
Data preprocessing
Customer behavior analysis
Elbow Method for optimal clusters
Customer segmentation visualization
Cluster-based insights
Dataset
Mall Customers Dataset

Outcome
Successfully segmented customers into different groups based on annual income and spending score to help businesses understand customer behavior and improve targeted marketing strategies.
